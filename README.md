# RITMO

Личный демонстрационный магазин повседневной одежды с сине-фиолетовым оформлением, локальным Manrope, русским интерфейсом и ценами в UZS. Next.js 16 / React 19 / TypeScript / Tailwind 4, Prisma 6 с JavaScript engine и SQLite-адаптером, Argon2id, Google GenAI SDK.

## Быстрый старт

Нужен Node.js 22 LTS. В этой облачной среде Node 22 также устанавливается как dev dependency: npm scripts автоматически используют его. Нативный better-sqlite3 собирается под версию Node, используемую при установке.

```sh
cd /workspace/project
cp .env.example .env  # только если .env ещё нет
export npm_config_cache=/workspace/.npm-cache
npm ci --ignore-scripts
# Сначала активируем Node 22, затем собираем нативный драйвер под него:
npm rebuild node
export PATH="$PWD/node_modules/.bin:$PATH"
npm rebuild better-sqlite3
npm run db:push
npm run db:seed
npm run dev
```

Production: `npm run build`, затем `npm start`. Порт по умолчанию 3000. `db:seed` повторяем: обновляет только демонстрационные изображения, сохраняет остальные данные товаров и остатки. SQLite хранится в `prisma/dev.db`; относительный DATABASE_URL разрешается относительно каталога prisma, абсолютный `file:/...` тоже поддерживается. Файл БД не коммитится: настройте постоянный диск и резервные копии. Для нескольких экземпляров/бессерверного хостинга требуется переход на PostgreSQL, его Prisma datasource и адаптер; текущий вариант рассчитан на один Node-сервер, не на эфемерный диск Vercel.

## Конфигурация

- `DATABASE_URL=file:./dev.db` — локальная база без внешней службы.
- `GOOGLE_API_KEY` — только на сервере. `GEMINI_MODEL=gemini-2.5-flash`. Без ключа работает явно обозначенный локальный подбор по каталогу: доступные товары, общий бюджет, состав и уход. При сбое Gemini также включается локальный режим. Запрос ограничен 1000 символами и 15 секундами; в модель не передаются профиль, заказы или история чата. Рекомендации проходят проверку ID по каталогу; карточки содержат серверные цены.
- `APP_URL` — точный origin приложения, например `https://shop.example.uz`. Используется для CSRF и ссылок восстановления; установите при публикации за reverse proxy.
- `SMTP_URL`, `MAIL_FROM` — почтовый транспорт и отправитель для восстановления пароля по email. Без них форма честно сообщает о недоступности. Без почтового сервиса для email- и телефонных аккаунтов доступно восстановление по одноразовому коду. SMS не используется.
- `SESSION_SECRET` из исходного SPEC не требуется: сессии используют 256-битные случайные непрозрачные токены, в БД хранится только SHA-256 токена, а не подписанный cookie.

Не включайте секреты в NEXT_PUBLIC_ переменные, git или сообщения чата. Production должен работать по HTTPS: cookie HttpOnly / Secure / SameSite=Lax, срок 30 дней. Пароли — Argon2id. Изменения проверяют Origin. Лимиты хранятся в БД, включая ограничения по идентификатору аккаунта и общие для экземпляра; IP-заголовки не считаются доверенными. Для публичной высокой нагрузки настройте отдельный rate limiting на доверенном reverse proxy. Токены восстановления одноразовые, действуют 30 минут, смена пароля завершает все сессии.

## Что работает

Главная, каталог с поиском/категорией/цветом/размером/ценой/сортировкой, страница товара, избранное, гостевая корзина в localStorage и корзина аккаунта в БД с загрузкой на другом устройстве, гостевой и авторизованный checkout, регистрация по email/телефону, вход/выход, профиль с адресной книгой (до 5 адресов), основным адресом, сменой пароля и собственной историей заказов. Сервер пересчитывает цены, объединяет дубли вариантов и атомарно списывает остатки с откатом при ошибке. Повтор checkout с тем же UUID и теми же данными возвращает существующий заказ без повторного списания; изменение данных под тем же ключом отклоняется. Подтверждение `/cart/order/:id` доступно владельцу аккаунта или гостю по отдельной HttpOnly cookie (7 дней), сохраняется после перезагрузки и поддерживает печать/PDF. Доставка 25 000 UZS, бесплатно от 500 000 UZS; только наличные. Валюта — целочисленная UZS. Интерфейс на русском; строки и форматирование можно вынести в словари при добавлении узбекского.

10 товаров и их характеристики — демонстрационные. Фотореалистичные изображения сгенерированы ИИ и хранятся локально; они иллюстративные. Перед реальными продажами замените их подтверждёнными фотографиями изделий. Доставка/оплата, юридические сведения, контакты и возвраты явно помечены как демонстрационные, реальные интеграции не подключены. Таблица размеров ориентировочная. Для реального запуска замените эти данные и опубликуйте юридические условия.

## Проверки

```sh
npm test              # 5 тестов: доставка, цены/остатки, идемпотентность, локальный подбор
npm run typecheck
npm run build
npm run test:e2e       # отдельная БД и автоматический тестовый сервер на порту 3100
npm start             # запуск личного проекта на порту 3000
```

`CHROMIUM_PATH` задаёт путь к Chromium (по умолчанию `/usr/bin/chromium`). Unit-тесты работают с отдельной `prisma/unit.db`. 6 E2E-сценариев автоматически создают/пересоздают только `prisma/e2e.db`, заполняют её демотоварами и запускают сервер на 3100; после тестов сервер останавливается. Личная `prisma/dev.db` не меняется. Перед E2E выполните `npm run build`. В тестовом сервере Gemini и SMTP отключены явно. Проверяются покупка, повторный вход, сохранение корзины между сеансами, адреса, восстановление/отзыв сессий, приватность гостевого подтверждения, защита от дублей, локальный стилист, клавиатура и адаптивность. Все изображения и шрифт локальные; внешняя сеть при просмотре магазина не нужна.

## Восстановление доступа без почты

При регистрации показывается 64-символьный код восстановления. Сохраните его вне сайта. В БД хранится только SHA-256 кода; он не записывается в localStorage и логи. На странице входа нажмите «Не помню пароль» → «По коду», введите аккаунт, код и новый пароль. Код одноразовый; успешное восстановление завершает все сессии. После входа создайте новый в разделе «Безопасность» (нужен текущий пароль). Смена пароля тоже аннулирует прежний код. Аккаунты, созданные до этой функции, могут создать код после обычного входа. Письма остаются дополнительным способом при настроенном SMTP.

Справочные страницы: `/help/delivery`, `/help/returns`, `/help/contacts`, `/help/privacy`. Это личный проект: реальные платежи, доставка, домен и публичные контакты продавца не требуются и не выдумываются. Gemini — опциональная внешняя интеграция, а локальный подбор не выдаётся за ответы модели.
